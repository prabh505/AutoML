## Context

FR-ING-06 asks for five bundled datasets (Titanic, House Prices, Adult Income, Telco Churn, Credit Default) plus a required multiclass sample, and says "Licenses MUST be verified before bundling [OPEN D-05]". This session could not verify any of those licenses, and Q-03 is still open. The P16 prompt says: "if a license is unverified, use an OpenML or synthetic alternative and record it".

D-14 asks for precomputed sample results, "clearly labeled 'precomputed on {date}'", for when the run slot is busy. CLAUDE.md §9 says not to commit generated artifacts.

§27.1 shows "sample dataset cards (5)", while FR-ING-06 asks for five samples plus one multiclass sample.

## Decision

1. **Six synthetic samples** are generated by `tabpilot.ingestion.samples` from fixed seeds. Five copy the column structure of the PRD's named datasets, and one is a multiclass land-cover sample. Each sample has a card titled "… (synthetic, task)", a pre-selected target, and the license note "Synthetic data generated by TabPilot (MIT license) … contains none of its records". No CSV is committed: a sample is written to `<data_dir>/samples/` on first use and is byte-identical every time (pinned numpy).
2. **Six cards** are shown, following FR-ING-06's "add one" (the §27.1 "(5)" counts only the source list).
3. **Precomputed results are committed** under `samples/precomputed/<sample_id>/`, 1.79 MB in 110 files. Each holds the leaderboard, selection, holdout, report (HTML, MD, JSON, facts, figures), `records/experiment.json`, `records/events.jsonl` and `precomputed.json` (date, profile, budget, LLM mode, status, version). There is no model, no bundle and no input data. They are regenerated with `scripts/precompute_samples.py`. The Results page labels them "Sample result precomputed on {date} … — not your data". Downloads are disabled for them.

## Alternatives

| Option | Pros | Cons | Why not chosen |
| --- | --- | --- | --- |
| Bundle the real datasets | Familiar to users | Licenses unverified (D-05) | Forbidden by FR-ING-06 until verified |
| OpenML datasets | Real data | Licenses and IDs need network verification that this session cannot do | Not verifiable here; the owner can still swap one in later |
| Generate precomputed results at app start | Nothing generated is committed | 6 runs × ~1–2 min on a 1 GB host at every cold start | Defeats D-14's purpose (instant result while busy) |

## Consequences

- Invariants: none affected. The samples go through the normal upload path (`RunManager.validate_sample`).
- FR-ING-06 AC ("each sample completes a run within SM-2"): all six completed under `scripts/precompute_samples.py` (hosted profile, 240 s budget, no LLM) in this session. These runs were in this container, not on REF-HOSTED (P18/P20).
- Risk: the synthetic data is less recognizable than the real datasets. The owner can replace a generator with a verified dataset without UI changes.
- The precomputed results must be regenerated when the report or leaderboard format changes. `test_committed_precomputed_results_are_labeled_and_readable` fails if they stop parsing.

## Status

Proposed by the implementer under the P16 prompt's explicit allowance. The owner should confirm item 1, and decide on Q-03 (real datasets) before P20.
